# Spielerbilder für HSG Kastellaun/Simmern

## Anleitung für Spielerbilder

### Dateinamen-Konvention
Die Spielerbilder müssen nach folgendem Schema benannt werden:

**Format:** `vor_nachname.jpg`

**Beispiele:**
- Max Mustermann → `max_mustermann.jpg`
- Anna Müller → `anna_mueller.jpg`
- Jörg Schmidt → `joerg_schmidt.jpg`

### Regeln für Dateinamen:
1. **Kleinbuchstaben** verwenden
2. **Umlaute ersetzen:**
   - ä → ae
   - ö → oe  
   - ü → ue
   - ß → ss
3. **Sonderzeichen entfernen** (außer Unterstriche)
4. **Leerzeichen durch Unterstriche** ersetzen
5. **Dateiendung:** `.jpg`

### Bildanforderungen:
- **Format:** JPG
- **Größe:** Mindestens 200x200 Pixel
- **Quadratisches Format** empfohlen
- **Gute Qualität** für scharfe Darstellung

### Beispiel-Dateien:
```
assets/players/
├── max_mustermann.jpg
├── anna_mueller.jpg
├── joerg_schmidt.jpg
├── lisa_weber.jpg
└── README.md
```

### Automatische Erkennung:
Das System erkennt automatisch:
- ✅ **Bild vorhanden** → Zeigt Bild + Name
- ❌ **Kein Bild** → Zeigt nur Name

### Unterstützte Spieler:
- Nur Spieler von **HSG Kastellaun/Simmern** (Gastteam)
- Andere Teams werden nicht angezeigt
